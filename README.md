# Saffron & Stone

A responsive one-page website for a fictional Afghan restaurant, designed with an original
editorial style inspired by the warmth and generosity of Afghan hospitality.

## Local development

```sh
npm install
npm test
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Customization

Update the restaurant name, address, telephone number, email addresses, menu, and social links in
`index.html` before using the website for a real business.
